# Skill Bridge English

Samostatná webová aplikace pro procvičování angličtiny. Spouští se přímo v prohlížeči, bez instalace.

## Spuštění přes GitHub Pages
1. Přidejte `index.html` do kořenové složky větve `main`.
2. V repozitáři otevřete **Settings → Pages**.
3. V části **Build and deployment** nastavte **Deploy from a branch**, **main**, **/(root)** a klikněte na **Save**.
4. Adresa po publikaci bude `https://novakbarbora.github.io/skillbridgeapp/`.

## Funkce
- A0–C1, ZŠ/SŠ/samouci
- Gramatika, slovní zásoba, stavba vět, čtení, poslech, psaní a kombinovaný test
- Tematické filtry a stručné gramatické taháky
- Okamžité vyhodnocování a ukládání statistik na zařízení

Žádné účty žáků ani serverová databáze: data jsou přímo v HTML. Poslech používá dostupné hlasy prohlížeče. Aplikace je výuková pracovní verze a nepředstavuje doslovný úplný import všech dřívějších učebnic.
